Proyecto personal

Lectio Divina

Una experiencia Android de lectura y reflexión, con historial local y recordatorios programados.

Contexto

La aplicación consulta la liturgia diaria por API y guía los pasos de Lectio Divina. Las reflexiones y citas se guardan en el dispositivo.

Mi contribución

Desarrollo de una aplicación Android personal con Kotlin y Jetpack Compose, integrando API, persistencia local y recordatorios.

Decisiones técnicas

  1. Estado e interfaz

    MVVM y StateFlow organizan el estado de las pantallas. Jetpack Compose compone las interfaces de lectura, reflexión e historial.

  2. Persistencia y red

    Room guarda reflexiones y citas en el dispositivo. Retrofit consulta la API de liturgia, manteniendo responsabilidades separadas.

  3. Recordatorios

    WorkManager y las notificaciones de Android permiten programar recordatorios. La entrega depende de permisos y condiciones del sistema.

Calidad y limitaciones

La organización de datos, repositorios, ViewModels y pantallas permite seguir el flujo entre consulta, estado y persistencia en el código público.

El contenido diario depende de una API externa. Las reflexiones se guardan en el dispositivo, lo que no implica disponer de toda la liturgia offline. Los recordatorios dependen de permisos y condiciones de Android.
