Proyecto personal

Clareza

Un producto web propio para organizar las finanzas, desde la interfaz hasta las reglas y la persistencia.

Contexto

Clareza reúne cuentas, ingresos, gastos, tarjetas, presupuestos, metas e inversiones. Creé el proyecto desde cero con Next.js, React, TypeScript y Firebase.

Mi contribución

Desarrollo del producto, reglas financieras, integración con Authentication y Firestore, importación CSV, pruebas automatizadas y configuración de entrega continua.

Decisiones técnicas

  1. Dinero y cuotas

    Los importes se representan en centavos enteros. Las cuotas conservan el total, incluso con redondeos. El pago de un extracto reduce el saldo sin contar el gasto dos veces.

  2. Revisión de importaciones

    La importación CSV incluye vista previa, identificación de posibles duplicados y sugerencias de categoría. Los datos se guardan tras la confirmación y las sugerencias se pueden cambiar.

  3. Datos por usuario

    Authentication identifica al usuario y las reglas de Firestore controlan el acceso a sus datos. El historial utiliza paginación por cursor y filtros en la base de datos.

Calidad y limitaciones

Las pruebas automatizadas cubren reglas monetarias, fechas, validación e importación. Las reglas de seguridad se prueban en el emulador Firestore. El pipeline está configurado para verificar código, tipos, pruebas y builds antes de publicar.

Sin integración bancaria ni cola offline. Los extractos admiten pago completo y la búsqueda textual puede requerir muchas lecturas. Las metas e inversiones no mueven dinero automáticamente.
